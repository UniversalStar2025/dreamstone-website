# DreamStone official website

Official website for Shanghai Dreamstone Network Technology Co., Ltd.

Production domain: https://www.dreamstonevr.com/

Static HTML, CSS and JavaScript, hosted with GitHub Pages from `main` / repository root. No build service is required. Portfolio images and App Store product assets are stored in this repository.

## Public routes

- `/` — studio, 12 iOS games, SelfScope, project portfolio, careers and contact.
- `/privacy` — original Privacy Policy, effective September 6, 2021.
- `/terms-of-service` — original Terms of Service, effective September 6, 2021.
- `/pages/cookie-policy` — original Cookie Policy with a current hosting note.
- `/app-ads.txt` — full original advertising configuration: 21,895 UTF-8 bytes, 485 lines.
- `/ads.txt` — intentionally empty, matching the original site configuration.

The original policy text, links and ad file content were checked during migration. The App Store catalog was verified against Apple's official US storefront developer catalog on September 13, 2026. Store availability can differ by region.

## Advertising files

Keep these files at the domain root. Do not deduplicate, reformat, normalize, or wrap their content in HTML. Preserve publisher IDs, case, punctuation, whitespace and Unicode characters exactly unless intentionally updating the advertising configuration.

Initial `app-ads.txt` SHA-256:

`5d502372986c74826b5ef714c11dd3e110c65add13d322b96498cf517fa61fbb`

`.gitattributes` prevents Git newline conversion for both advertising files. `.nojekyll` disables Jekyll processing.

## Editing and deployment

Update the HTML, `style.css`, `script.js`, or image files, then commit to `main`. GitHub Pages publishes the new commit. Keep the custom domain set to `www.dreamstonevr.com` in repository Settings → Pages.

The contact form creates a mail draft in the visitor's own email application. It does not store or send messages from a server. The site does not install analytics or advertising cookies.

The hero artwork is original AI-generated brand illustration. App icons and complete official screenshots are product content. No interface elements were cropped or extracted from screenshots.
